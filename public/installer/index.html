🚀 Support Board Installation

Step-by-step setup wizard for your support platform

Welcome!

This wizard will guide you through setting up Support Board PHP.

What this installer does:
1. Configures your MySQL database connection
2. Creates the database schema (migrations)
3. Seeds demo data (users, departments, articles)
4. Sets up vLLM / LLM integration for the chatbot
5. Configures the web crawler

Requirements

  • ? PHP 8.1+ installed
  • ? MySQL / MariaDB running
  • ? Composer installed
  • ? Laravel dependencies present

Database Configuration

Enter your MySQL connection details.

You'll need your MySQL host, port, database name, username, and password. If the database doesn't exist, the installer will try to create it.
Usually 127.0.0.1 or localhost

Install & Configure

We'll run migrations, seed data, and configure vLLM.

This step will:
• Generate application keys
• Run all database migrations
• Seed demo data (admin, agent, user accounts)
• Configure vLLM for the chatbot AI
vLLM, Ollama, or OpenAI compatible endpoint
